# Research/

Sprindi tausta-uuringud, audit'id ja otsus-jäljed.

## Tüüpilised failid

- `initial-audit.md` — Phase 0 ajal: olemasoleva koodi/disaini ülevaade selle feature osas
- `adversarial-review.md` — pre-implementation gate: kriitiline arvustus enne koodi muutmist
- `prototype-feedback.md` — H4 prototüübi-katsetamisest tekkinud spec-lüngad
- `stakeholder-feedback-<kuupäev>.md` — kohtumiste kokkuvõte ja otsused
- `decisions.md` — sprindi käigus tehtud disainotsuste jälg (ADR-stiilis)

## Loogika

Need failid pole **publik** dokumentatsioon — need on sprindi sisesed töödokumendid, mis aitavad sprindi-meeskonnal ühises kontekstis püsida. Pärast sprindi lõpetamist arhiveeritakse koos ülejäänud sprint-paketiga.
